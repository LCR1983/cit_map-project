# 🎨 フロントエンド 仕様書 (HTML / CSS / JavaScript)

## 1. フロントエンド アーキテクチャ
フロントエンドは、フレームワーク（ReactやVue）に依存しない **Vanilla Web Stack (HTML5, CSS3, ES6 JavaScript)** で構築されています。
外部のUIライブラリやグラフ描画ライブラリを一切使用しないことで、ブラウザの強力なCSP（コンテンツセキュリティポリシー）に違反せず、あらゆる環境（大学のPCルーム等）で確実に動作する軽量かつ堅牢な設計となっています。

---

## 2. ディレクトリ構成
```text
app/frontend/
 ├── index.html     (一般ユーザー向け マップ・検索・評価画面)
 ├── admin.html     (管理者向け ダッシュボード・AI分析画面)
 ├── style.css      (一般画面用 スタイル定義)
 ├── admin.css      (管理者画面用 スタイル定義)
 ├── script.js      (一般画面用 ロジック・API通信・UI制御)
 ├── admin.js       (管理者画面用 ロジック・グラフ描画・AI連携)
 ├── data.js        (特産品やルート検索等のマスタデータ定義)
 ├── nginx.conf     (Nginxのリバースプロキシ設定)
 └── Dockerfile     (コンテナビルド定義)
```

## 3. UI/UX デザイン原則
*   **サイバーパンク・ダークネオンテーマ:** 
    *   背景色は深いダークブルー/ブラック（`#0d1117`, `#161b22`）を基調。
    *   アクセントカラーにシアンブルー（`#00c6ff`）、警告色にネオンゴールド（`#ffc107`）、成功色にネオングリーンを使用し、輝くドロップシャドウ（`box-shadow`, `drop-shadow`）を多用。
*   **ガラスモルフィズム (Glassmorphism):**
    *   モーダルやカードの背景に `rgba(255, 255, 255, 0.05)` と `backdrop-filter: blur(10px)` を適用し、未来的で奥行きのあるすりガラス表現を実現。
*   **マイクロインタラクション:**
    *   ホバー時の滑らかなトランジション（`transition: 0.3s`）や、AIローディング中のCSSスピナーアニメーションを実装。

## 4. 機能仕様：一般画面 (`index.html` / `script.js`)

### 4.1 マップ連動機能
*   **特産品ピン描画:** `data.js` に定義された特産品の緯度経度に基づき、CSSの絶対配置でマップ画像上にピン（📍）を動的レンダリング。
*   **詳細モーダル表示:** ピンをクリックすると、画面全体を覆うガラスモルフィズムモーダルが開き、特産品の詳細（画像、説明、Googleマップ検索リンク）を表示。

### 4.2 評価ツール (Rating Form)
*   **星評価UI:**
    *   5つの星（`⭐`）アイコンを配置し、ホバー・クリックイベントで動的に `active` クラスを切り替え、選択値を保持。
*   **API送信:**
    *   「評価を送信」ボタン押下時、星の数とコメントを JSON 形式で `POST /api/ratings` へ非同期送信（`fetch` API）。
    *   レスポンスに応じて、カスタムトースト通知（画面上部からスライドインするメッセージ）を表示。

### 4.3 AIレシピチャット (Gemma2連携)
*   **レシピ生成:** 任意の食材名を入力し送信すると、Ollamaを通じてGemma2が考案したレシピをMarkdownからHTMLへ変換（`marked.js`）して表示。
*   **追加チャット（質問）機能:** 生成されたレシピの下部にチャット入力欄を配置。「あなた：」として送信内容を画面に即座にレンダリングし、その後AIからの回答を追記するインタラクティブなチャット機能。

## 5. 機能仕様：管理者画面 (`admin.html` / `admin.js`)

### 5.1 認証 ＆ セッション管理
*   **ログインUI:** 初期状態ではダッシュボードを `hidden` にし、ログインフォームのみを表示。
*   **セキュリティ処理:** ログイン成功後、発行された `HttpOnly` セッションクッキーと同時に返却される **CSRFトークン** を、以降のすべてのAPIリクエストヘッダー（`X-CSRF-Token`）に自動付与する通信モジュールを実装。

### 5.2 評価コメント管理タブ
*   **CSS ドーナツ型円グラフ:**
    *   外部JSライブラリを使用せず、CSSの `conic-gradient` プロパティを JavaScriptで動的生成。
    *   全評価データを集計し、各星の割合（%）に応じてグラデーションの角度を計算し、`style.background` に注入。中央に総合平均点を表示。
*   **グローバルタイムゾーン自動追従テーブル:**
    *   バックエンドから UTC（協定世界時）のISO文字列（例: `2026-05-22T13:49Z`）で届いた日付データを、`new Date(item.createdAt).toLocaleString()` によって、ブラウザを閲覧している管理者のOSロケール（現在地）の時刻へ完璧に自動変換してレンダリング。

### 5.3 AI自動評価分析UI
*   **プログレッシブローディング:** 「AIで分析」ボタン押下時、ボタンをスピナー（ローディング状態）に置換し、二重送信を防止。
*   **ハルシネーション免責警告:** AI出力の不確実性を示すため、左端が警告ゴールドで光る免責事項カードをレポートエリア直下に常設。
